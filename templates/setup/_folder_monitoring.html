Folder Monitoring

CLU watches a download folder (WATCH) and processes every comic that lands in it, converting, renaming and then moving it to a holding folder (TARGET). Downloads, the Wanted list and the Mylar3 import all deliver through these two folders, so they must be outside /data.

Folders
Save the folders first.
Processing
Removes scanner and release-group tags and other clutter, leaving a name like Series 001 (2024).cbz. Works from the file name alone, so no metadata is needed. This is not renaming from metadata.
Bulk and automatic tagging rename each comic they tag to this pattern, filled from its metadata. With clean-up on, files leaving WATCH use it too, filled from the file name and any ComicInfo.xml. A token with nothing to fill it is left out.
From the file name: {series_name} {issue_number} {volume_number}. Need metadata: {issue_title} {issue_year} {issue_month_m} {issue_month_M}. {volume_year} is the series start year from metadata; without it, the year in the file name.
