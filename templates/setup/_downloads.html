Downloads

CLU can fetch the issues on your Wanted list from three sources. Auto-download tries the sources that are on, in the order below, and every download is delivered through the WATCH folder. GetComics needs no setup; Usenet and DC++ need a client you already run.

{# Usenet #}
Usenet client

CLU moves a finished download into WATCH from the folder the client reports, so the client’s completed-downloads folder must be mapped into CLU at the same path. If it is not, the download finishes but stays where the client put it.

Indexers

Usenet needs at least one Newznab indexer to search.

{# DC++ #}
AirDC++

Hubs are set up inside AirDC++ itself; CLU searches the ones it is connected to.

AirDC++ reports paths as it sees them. Target Directory is where it saves finished downloads, written the way AirDC++ sees it. If CLU sees that folder at a different path (AirDC++ on Windows, or in its own container), put CLU’s path in Target Directory (as CLU sees it).

Search variants, custom headers and more in Settings → Download API and Download Clients · Documentation · Usenet · Indexers · Source priority
