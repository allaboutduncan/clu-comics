Asks the provider that tagged each file in (and its subfolders) for the same issue again, and adds only the tags that are blank in the file.

  • Values already in the file — including ones you edited — are never changed.
  • Files with no recognised provider, or tagged by hand, are skipped.
  • Every file looked up is one provider request, so a large folder can take a while and counts against API limits.
