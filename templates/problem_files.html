Unless you turn on the library health scan above, CLU does not look for damage on its own — a file appears here when something tried to read it and could not, so an empty page means nothing has failed, not that the library is clean. With the scan on, the card shows how much of the library has been checked. Scan series.json finds series.json files with a blank name, description or cover.

Looking for files tagged by the wrong metadata provider? That is not a failure, so it is not listed here — open a folder's menu in the File Manager and choose Re-tag with provider… to see which providers tagged it and re-tag from one.
