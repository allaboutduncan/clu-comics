A series in CLU points at one folder. Scan Library lists a folder here when its series.json or cvinfo names a series that already points somewhere else, or when two folders name the same series. Only the comics in the mapped folder count as owned, show on the series page and get matched to issues.

Compare & merge lists both folders' comics side by side, paired by issue number. Merge moves this folder's comics into the mapped folder and, for an issue in both, keeps the copy you pick and trashes the other. Drop duplicates only trashes this folder's copies of issues the mapped folder already has. A folder left with no comics goes to the trash too. Nothing overwrites a file: a name already taken by a different comic is left where it is and reported.

When several series in one parent folder are all mapped under another parent (/data/Image beside /data/Image Comics), a card above the list offers Merge all. It shows a dry run first, then merges each series with the suggested copies kept. Folder names that differ only by case or punctuation are marked likely the same folder.

Use this folder instead makes this folder the series' folder; the old one then takes its place on this list. Ignore keeps both folders as they are and stops listing this one until a comic is added to or removed from it.
