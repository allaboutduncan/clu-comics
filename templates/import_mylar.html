1. Load Mylar's files

Mylar keeps mylar.db and config.ini in its data folder (/config/mylar/ in the linuxserver image). Copy them while Mylar is stopped, or use the copy in Mylar's backup folder. Either file can be imported on its own.

Or copy them into {{ drop_folder.path }}: mylar.db {{ 'found' if drop_folder.mylar_db else 'not found' }}, config.ini {{ 'found' if drop_folder.config_ini else 'not found' }}
2. Where Mylar's folders are in CLU

Mylar records its own container's paths. Each Mylar folder on the left is replaced by the CLU folder on the right. A series folder that does not exist yet is created, as Subscribe does.
